# Culinary Workspace

Restaurant and café management workspace built with Next.js.

## Modules

- **Menu** — dishes, categories, and pricing
- **Orders** — order intake and kitchen workflow
- **Reservations** — table and slot management
- **Marketing** — offers and promotions

## API

All modules are exposed through REST route groups under `app/api/`.

## Running

```bash
bun install
bun run dev
```

See `app/api/customers` and related route folders for the module
implementations.
